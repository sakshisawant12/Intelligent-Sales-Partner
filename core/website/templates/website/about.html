About Intelligent Sales Partner

AI-powered sales automation platform designed to help businesses convert visitors into customers efficiently.

Founder

Hi, I'm Soham Jadhav, a BSc IT student passionate about Artificial Intelligence and automation.

I built Intelligent Sales Partner (ISP) to help businesses automate customer conversations, capture leads, and improve response time using intelligent systems.

What started as a college project is evolving into a production-ready SaaS platform.

Mission

To help businesses automate sales communication, reduce manual workload, and improve customer response time through reliable and scalable AI-powered systems.

Vision

To build intelligent automation solutions that empower businesses worldwide to operate smarter, faster, and more efficiently using advanced AI technology.

Tech Stack

Django

Backend framework managing authentication, business logic, and database communication.

Tailwind CSS

Used to build a responsive and modern user interface.

Groq API (LLaMA)

Powers AI chatbot conversations and automated responses.

SQLite

Stores users, leads, domains, and conversation data.

Gmail SMTP

Sends automated notifications and marketing emails.

Real-Time Dashboard

Allows monitoring of leads, conversations, and system activity.
